▸ SYNC MULTI-APPAREILS GRATUIT · COMPTE FIREBASE REQUIS
● NON CONFIGURÉ

Synchronise tâches, projets, agenda, notes, finances, habitudes, contacts, bookmarks et journal en temps réel entre tous tes appareils connectés au même compte. Configure une fois, connecte-toi ensuite sur chaque appareil avec le même email.

1 · Va sur console.firebase.google.com → Ajouter un projet (gratuit, plan Spark)
2 · Menu Build → Firestore Database → Créer une base de données (mode production, choisis une région proche)
3 · Onglet Règles de Firestore → remplace tout par ceci et publie :
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == uid; } } }
4 · Menu Build → Authentication → Sign-in method → active E-mail/Mot de passe
5 · Paramètres du projet (⚙ en haut à gauche) → Général → Tes applications → Ajouter une app Web (icône </>) → copie les 4 valeurs ci-dessous
La config (clé API, domaine…) n'est pas un secret côté Firebase — l'accès est protégé par les règles Firestore ci-dessus, pas par la confidentialité de ces valeurs.

▸ NOTION SYNC — DEUX SENS GRATUIT · CLOUDFLARE WORKER REQUIS
● NON CONFIGURÉ

Le statut d'une tâche se synchronise dans les deux sens (le plus récemment modifié gagne). Créer/déplacer une tâche sur Notion l'importe ici ; cocher "envoyer les nouvelles tâches" pousse aussi tes tâches créées dans Jarvis vers Notion.

ÉTAPE 1 — Proxy CORS (Cloudflare Worker gratuit, ~2 min)
1 · Va sur workers.cloudflare.com → compte gratuit → Create a Worker
2 · Remplace tout le code par celui-ci et clique Deploy :
export default { async fetch(req) { const url = new URL(req.url); const target = 'https://api.notion.com' + url.pathname + url.search; const h = new Headers(req.headers); h.set('Notion-Version', '2022-06-28'); const cors = { 'Access-Control-Allow-Origin': '*', 'Access-Control-Allow-Methods': 'GET,POST,PATCH,DELETE,OPTIONS', 'Access-Control-Allow-Headers': 'Content-Type,Authorization,Notion-Version' }; if (req.method === 'OPTIONS') return new Response(null, { headers: cors }); const r = await fetch(target, { method: req.method, headers: h, body: req.method !== 'GET' ? req.body : null }); const rh = new Headers(r.headers); Object.entries(cors).forEach(([k, v]) => rh.set(k, v)); return new Response(r.body, { status: r.status, headers: rh }); } };
3 · Copie l'URL du Worker déployé (ex: https://mon-worker.moncompte.workers.dev)

export default { async fetch(req, env) { const url = new URL(req.url); const cors = { 'Access-Control-Allow-Origin': '*', 'Access-Control-Allow-Methods': 'GET,POST,PATCH,DELETE,OPTIONS', 'Access-Control-Allow-Headers': 'Content-Type,Authorization,Notion-Version,x-api-key,anthropic-version' }; if (req.method === 'OPTIONS') return new Response(null, { headers: cors }); let target, h = new Headers(req.headers); if (url.pathname.startsWith('/anthropic/')) { target = 'https://api.anthropic.com' + url.pathname.replace('/anthropic', '') + url.search; h.set('x-api-key', env.ANTHROPIC_API_KEY); h.set('anthropic-version', '2023-06-01'); h.delete('host'); } else { target = 'https://api.notion.com' + url.pathname + url.search; h.set('Notion-Version', '2022-06-28'); } const r = await fetch(target, { method: req.method, headers: h, body: req.method !== 'GET' ? req.body : null }); const rh = new Headers(r.headers); Object.entries(cors).forEach(([k, v]) => rh.set(k, v)); return new Response(r.body, { status: r.status, headers: rh }); } };
